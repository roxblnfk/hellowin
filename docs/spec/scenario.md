# Сценарий и правила игры

Статус: правила сцены, тыкв, раунда и сброса — **в работе** (движок переписывается); игроки — **запланировано**.

## Сюжет

RoadRunner «умер». Посетители страницы вместе проводят ритуал воскрешения: каждый клик по тыкве двигает общий прогресс,
все видят действия всех в реальном времени. Ритуал идёт сценами (например: склеп → вырезание тыкв → зажигание →
воскрешение), но смысл и вид каждой сцены решает фронтенд — движок знает только номера.

## Сцена

- `scene` — целое от 0 до `HELLOWIN_SCENE_STAGES` (env). 0 — начальная, `HELLOWIN_SCENE_STAGES` — финал.
- Сцена s переходит в s+1, когда **все** тыквы достигли стадии s+1. Условие вынесено в политику (одна точка в коде),
  его можно заменить без переписывания движка.
- В финальной сцене тыквы больше не переходят; клики продолжают рассылаться как события.

## Тыквы

- Набор тыкв и их позиции — `app/config/hellowin.php` (`elements`). Сейчас все элементы — тыквы.
- У каждой тыквы своя `stage` (целое, от 0) и свой счётчик `clicks`.
- Тыква может перейти только в стадию `scene + 1` — выше сцены не убегает.
- Порог перехода — `HELLOWIN_CLICKS_PER_STAGE` кликов по этой тыкве. После порога каждый следующий клик ставит
  в очередь задачу перехода, пока переход не выполнен; выполняется ровно один переход, он обнуляет `clicks`.
  Клики сверх порога, сделанные до выполнения перехода, сгорают — это часть демонстрации.

## Раунд и сброс

- `round` — номер прохода ритуала, растёт при сбросе. Входит во все ключи идемпотентности, иначе после сброса переходы
  были бы заблокированы навсегда.
- Сброс: сцена 0, все тыквы — стадия 0 и 0 кликов, `round + 1`, событие `reset` всем. Сброс защищён от двойного
  выполнения.
- Кто запускает сброс — **не решено**: варианты — голосование подключённых или голосование кликами. Пока — консольная
  команда `hellowin:reset`.

## Игроки

**Запланировано**, детали — [`players.md`](players.md). Игрок вводит имя, браузер держит постоянный секретный ID;
по игроку считаются клики и «добитые» тыквы (чья задача перехода выполнилась), есть таблица лидеров.
