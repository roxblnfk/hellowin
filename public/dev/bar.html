Арт бара (pixel/bar.js) с DEFAULT_BAR_LAYOUT. Параметры: ?light=day|firelight|… (свет, по умолчанию firelight), ?t=мс (стоп-кадр пламени и розлива), ?zoom=N (масштаб кадров, по умолчанию 5), ?sheet (только кадры, без залов; ?sheet=owl — только сова и позы), ?mugs=N (кружек на стойке в зале, по умолчанию 3), ?boxes — контуры препятствий (зелёные), места у стойки и пол под мебелью с полуфигуркой по бокам (красный: должен лежать внутри препятствия), места посадки мух (жёлтые линии: должны лежать на верхнем крае своей вещи) и порог двери с путём входа (голубые), ?door=0…3 — кадр двери (0 закрыта, 3 распахнута), ?sizes=1920x1080,390x844 — только залы этих размеров, ?layout=JSON — раскладка вместо копии конфига (например, walk.bar из #app[data-bar-layout] живого стенда).
